# 追光者 Lumen Arc v0.5 — 使用手册

## 工具简介

**追光者 Lumen Arc** 是一款火灾调查视频亮度分析桌面工具：在视频画面上框选感兴趣区域（ROI），自动逐帧计算每个区域的平均亮度，绘制亮度-时间折线图，支持截图融合对比、放大镜查看细节、倍速播放等功能。

## 快速开始

### 第一步：安装依赖（仅需一次）

双击运行 `setup_python_deps.bat`，脚本会自动检测/安装 Python 及所需依赖（opencv + numpy）。

> 如果脚本提示需要手动安装 Python，前往 https://www.python.org/downloads/ 下载安装（安装时勾选 **"Add Python to PATH"**），装完后再双击 bat 一次。

### 第二步：启动程序

双击 `LumenArc.exe`。

> 如果 Windows 弹出 "Windows 已保护你的电脑" 提示，点击「更多信息」→「仍要运行」。

## 操作流程

### 1. 打开视频

- **菜单**：`文件 → 打开视频...`（或按 `Ctrl+O`）
- **拖放**：直接把视频文件拖入程序窗口
- 支持格式：MP4、AVI、MKV、MOV、WMV、FLV、WEBM

### 2. 框选分析区域 (ROI)

- **绘制**：在视频画面上按住鼠标左键拖拽，画出矩形框
- **移动**：点击选中（边框增亮），再次拖拽移动
- **调整大小**：选中后拖拽四角的白色方块
- **删除**：选中后按键盘 `Delete` 键
- **放大镜内操作**：在放大镜视图中也可绘制/调整 ROI，坐标自动映射回主视频
- **数据保护**：调整已有分析数据的 ROI 时，会弹出确认提示，防止误操作导致数据丢失
- 支持多个 ROI，每个颜色不同（赤橙黄绿青蓝紫）

### 3. 运行分析

点击工具栏上的 **"分析"** 蓝色按钮，程序会逐帧扫描整个视频并计算每个 ROI 的平均亮度。分析完成后弹出报告。

> 长视频分析可能需要数分钟，进度条会显示进度。可随时按「取消」停止。

### 4. 查看结果

分析完成后，下半部分的折线图会显示亮度-时间曲线：

| 操作 | 方式 |
|------|------|
| 拖拽光标跳转 | 点击/拖拽青色竖线，视频会同步跳转 |
| 缩放时间轴 | 鼠标滚轮（以光标位置为中心） |
| 平移时间轴 | 按住鼠标中键拖拽，或 `Shift + 左键` 拖拽 |
| 恢复全局视图 | 双击图表区域 |
| 设置时间标签 | 点击 **"设置时间"** 输入真实时间（如 `10:30:00`） |
| 时间轴刻度 | 自动显示刻度尺（主刻度+次刻度），右键可切换显示/隐藏 |

### 5. 图表标签

在折线图上添加文字标签来标记关键时刻：

- **添加**：双击图表区域 → 输入文字 → 点击色块选择颜色（或直接回车随机分配颜色）
- **跳转**：单击标签 → 视频自动跳转到标签所在的精确帧
- 标签在缩放/平移图表后始终锚定在正确的时间位置

### 6. 倍速播放

点击播放按钮旁的倍速按钮（显示当前速度），点击循环切换：

```
0.25x → 0.5x → 1x → 2x → 4x → 8x → 0.25x
```

也可使用快捷键：`c` 加速、`x` 减速、`z` 恢复 1x。

停止播放时自动重置为 1x。

### 7. 放大镜

滚轮在视频画面滚动即可创建放大镜（停靠在右侧），用于查看局部细节：

| 操作 | 效果 |
|------|------|
| 滚轮（视频上） | 创建放大镜 / 以鼠标位置为中心缩放（1.5x ~ 10x） |
| 滚轮（放大镜内） | 以放大镜内鼠标位置为中心缩放 |
| 中键拖拽 | 平移放大镜视图（主视频和放大镜内均生效） |
| `Esc` 或右键菜单 | 关闭放大镜 |

> 可以在放大镜视图内直接绘制或调整 ROI，坐标会自动映射回主视频。

### 8. A/B 区域循环播放

| 操作 | 效果 |
|------|------|
| `A` 键 | 在当前播放位置设置 A 点 |
| `B` 键 | 在当前播放位置设置 B 点 |
| 自动循环 | 设置 A/B 后自动开启循环 |
| `L` 键 | 切换循环开/关 |
| 右键菜单 | 清除 A/B、缩放到区域 |

### 9. 截图融合

截取视频帧作为半透明叠加层，便于对比不同时刻的画面差异：

1. 点击 **"截取"** 截取当前帧 → 左侧出现缩略图
2. 点击缩略图展开编辑器（大图预览 + 亮度/对比度/透明度滑块）
3. 再次点击预览图可折叠回缩略图模式
4. 拖拽滑块调整参数，实时预览效果
5. 点击 **"放置"** 将叠加应用到视频画面（工具栏按钮和编辑器内按钮均可操作）
6. 点击 **"清除"** 或 **"关闭"** 取消叠加

### 9. 保存与导出

| 功能 | 菜单路径 | 格式 |
|------|---------|------|
| 保存分析结果 | `文件 → 保存分析结果...` | `.vla`（含 ROI + 亮度数据 + 截图融合图像+参数） |
| 加载历史结果 | `文件 → 加载分析结果...` | `.vla` |
| 导出 CSV | `导出 → 导出为 CSV...` | `xxx.csv`（亮度数据）+ `xxx_labels.csv`（标签） |

> 分析完成后会自动在同目录生成 `视频名.vla` 缓存文件，下次打开视频时会被检测到并询问是否直接加载。

## 文件格式说明

### .vla 文件（分析结果缓存）

JSON 格式，包含完整分析结果、ROI 位置、放大镜、标签、固定时间戳、截图融合图像和参数：

```json
{
  "version": 3,
  "regions": [{"x": 100, "y": 200, "w": 300, "h": 150}],
  "time_offset": 36000000,
  "timestamps": [0, 33, 66, ...],
  "luminances": [[128.5, 130.2, ...]],
  "magnifier": {"x": 100, "y": 200, "w": 300, "h": 250},
  "labels": [{"time_ms": 5000, "text": "门开了", "color": "#ff0000"}],
  "pinned": {"x": 1200, "y": 10, "w": 200, "h": 30},
  "snapshot_fusion": {
    "brightness": 10,
    "contrast": -5,
    "opacity": 70,
    "image": "iVBORw0KGgoAAAANSUhEUgAA..."
  }
}
```

### CSV 导出格式

亮度数据文件：
```
Time(ms),Time,R1_Brightness(x100_y200_300x150)
0,10:30:00,128.5
33,10:30:00,130.2
```

标签数据文件（`_labels.csv`）：
```
Time(ms),Time,Text,Color
5000,10:30:05,门开了,#ff0000
12000,10:30:12,车来了,#00ff00
```

## 常见问题

| 问题 | 解决方法 |
|------|---------|
| 分析失败 "Python executable not found" | 运行 `setup_python_deps.bat` 安装 Python |
| 分析失败 "opencv not found" | 运行 `setup_python_deps.bat` 装依赖 |
| 打开视频黑屏 | 确认视频格式支持（不支持的格式先转为 MP4） |
| DAV 格式无法打开 | DAV 是大华私有格式，请用转换工具转为 MP4 |
| 图表时间标签超出 24 小时循环 | 当前限制，监控录像一般不超 24h |
| 截图融合不显示 | 需先点击"截取"，再点击"放置"才叠加到视频 |
| 放大镜内 ROI 操作不生效 | 放大镜锁定后，需在放大镜视图内直接操作 ROI |
| VLA 文件打不开 | 版本不兼容，v0.2 的 VLA 无法在 v0.1 打开 |
