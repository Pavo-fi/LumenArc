# 追光者 Lumen Arc

面向火灾调查的视频分析桌面工具。支持在视频中框选感兴趣区域（ROI）进行逐帧亮度量化分析，绘制亮度-时间曲线；同时支持独立音频分析（音量曲线 + 语谱图）、截图叠加、A/B 循环、辅助线标注等功能。

---

## 主要功能

| 功能 | 说明 |
|------|------|
| 亮度量化分析 | 框选矩形或多边形 ROI，逐帧计算区域平均亮度并绘制曲线 |
| 音频分析 | 无需 ROI，直接提取音轨并生成音量曲线和语谱图 |
| 语谱图 + 降噪 | 可视化音频频谱，支持频谱门控降噪 |
| 多视频分析 | 视频列表支持添加多个视频，可快速复制/粘贴 ROI |
| 放大镜 | 局部放大查看视频细节，支持在放大镜内绘制和调整 ROI |
| 截图叠加 | 截取视频帧或加载外部图片，半透明叠加到当前视频 |
| 时间戳提取 | 固定一个区域，实时显示在独立浮动窗口中 |
| 时间设置 | 将图表时间轴与真实世界时间（HH:MM:SS）对应 |
| 轴标签 | 在折线图上添加文字标记，标注关键时刻 |
| A/B 区域循环 | 在图表上设置 A/B 两点，两点之间循环播放 |
| 辅助线 | 在视频画面上绘制水平、垂直或斜向参考线 |
| 分析结果共享 | 分析成果保存为 `.vla` 文件，支持跨终端传递 |
| 前处理 | 多视频智能排序（画面 OCR 时间戳为硬证据）、无损拼接、非 MP4 统一转码，输出可留档的证据报告 |

---

## 播放内核

使用自研 **FFmpeg 播放内核**：对监控视频常见的“伪 MP4”（MPEG-PS/TS 改扩展名、无索引、起始时间戳偏移）提供精确到单帧的进度拖拽与逐帧步进。支持 D3D11VA 硬件解码（`设置` 中可开关、可指定适配器），拖拽进度时自动切换多线程软解追赶以保证落点精度。

> FFmpeg 内核倍速播放时音频变速（音调随速度变化），拖拽进度时播放与光标对齐的短音频片段。

## 下载与安装

1. 访问 [Releases 页面](https://github.com/Pavo-fi/LumenArc/releases)，下载最新 `LumenArc-vx.x.x-win64.zip`。
2. 解压到任意目录。
3. 双击 `LumenArc.exe` 启动。

> 首次启动若 Windows 提示"Windows 已保护你的电脑"，点击「更多信息」→「仍要运行」。

Release 包已内置 Python 和 ffmpeg，无需手动安装。

## 系统要求

### 最低配置（1080p 素材流畅，1440p 可播放）

| 部件 | 规格 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 1809+ 64位 | Qt 6.8 运行库的硬性要求 |
| CPU | 4 核（i5-6500 / Ryzen 3 1200 级，2016 年后） | 1440p H.264 软解实时播放约需 2~3 个现代核心，更慢可开硬件解码兜底 |
| 显卡 | 任意支持 D3D11 的核显（Intel HD 4000+ / AMD APU） | 硬解走 D3D11VA，H.264 为近十余年 GPU 标配，无需独显 |
| 内存 | 8 GB | 拖拽滚动缓存上限 60 帧（1440p 约 11MB/帧 ≈ 660MB）+ 系统余量 |
| 存储 | 机械硬盘可读，素材建议放 SSD | 快速拖拽 = 反复随机 seek，长视频在机械盘上冷 seek 有可感延迟 |
| 显示器 | 1920×1080 | 视频区 + 双图表 + 语谱图布局的下限 |

### 推荐配置（1440p 素材快拖顺滑、分析快）

| 部件 | 规格 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 22H2 / Windows 11 64位 | |
| CPU | 6 核 12 线程以上（i5-12400 / Ryzen 5 5600 级） | 实测 1440p 软解 ~536fps、硬解 ~750fps（≈31 倍速）是“快拖指哪播哪”的物理基础；核心越多，拖拽追赶阶段越顺滑 |
| 显卡 | Intel UHD 620+ / 任意近代核显或独显 | 1440p H.264 硬解零压力；GPU 只参与解码，画面绘制为 CPU 路径 |
| 内存 | 16 GB | 长视频分析时 Python（numpy + OpenCV）峰值数百 MB，与视频缓存并行不挤 |
| 存储 | NVMe / SATA SSD 存放素材 | 拼接长视频 seek 密集，SSD 冷 seek <1ms（机械盘 10~20ms），直接影响快拖起步手感 |
| 显示器 | 2560×1440 或以上 | 监控素材本身为 1440p，1:1 观察 + 图表并排不吃力 |

> **要点**：本软件不吃显卡（解码靠核显 D3D11VA，绘制走 CPU），预算优先给 CPU 和 SSD；性能瓶颈实测排序为：素材在机械盘的冷 seek > CPU 软解吞吐 > 内存。

## 快速开始

### 打开视频

- 菜单：`文件 → 打开视频`（或按 `Ctrl+O`）
- 拖放：直接把视频文件拖入程序窗口
- 支持格式：MP4、AVI、MKV、MOV、WMV、FLV、WEBM 等常见格式

### 框选分析区域

- 工具栏选择「矩形」或「多边形」模式
- 矩形：按住鼠标左键拖拽绘制
- 多边形：单击添加顶点，双击闭合
- 选中后可移动、调整大小，按 `Delete` 删除

### 运行分析

- 点击工具栏 **「亮度分析」** 按钮，逐帧计算 ROI 平均亮度
- 点击工具栏 **「音频分析」** 按钮，无需 ROI 即可生成音量曲线和语谱图
- 分析完成后自动在视频同目录生成 `.vla` 缓存文件，下次打开视频时可直接加载

### 查看图表

- 拖拽图表中的橙色竖线，视频同步跳转
- 滚轮缩放时间轴，中键拖拽平移
- 双击图表区域恢复全局视图

## 开发与构建

项目使用 Qt + CMake 构建。本地源码开发版需自行配置 Python 环境并确保 ffmpeg 在 PATH 中或在 `portable/ffmpeg` 目录下。

```bash
mkdir build && cd build
cmake ..
cmake --build . --config Release
```
