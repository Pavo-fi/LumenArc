# 大华录像机直连 — 网卡一键配置

给 LumenArc「接入监控直播」用的配套小工具：**把本机网卡的 IP 改成与录像机同网段**，
省掉手动进"网络和 Internet → 更改适配器选项"改 IP 的步骤。

## 为什么需要它

网线直连（录像机 ↔ 本机网口）时，这段链路里**没有 DHCP 服务器**。
Windows 拿不到地址，就会给网卡一个 `169.254.x.x` 的自动地址（APIPA），
结果就是：`ping` 不通、RTSP 554 连不上、LumenArc 一直"连接失败"。

必须手工把本机网卡设成与录像机同网段的静态地址，例如：

| | 值 |
|---|---|
| 录像机（大华出厂默认） | `192.168.1.108` |
| 本机网卡 | `192.168.1.100` |
| 子网掩码 | `255.255.255.0` |

本工具就是把这个动作自动化，并且**可一键还原**。

## 文件清单

| 文件 | 用途 |
|---|---|
| `configure_directlink.bat` | **双击这个**：自动提权 → 配置静态 IP |
| `restore_dhcp.bat` | **双击这个**：还原成原来的配置（自动获取 IP） |
| `configure_directlink.ps1` | 实际逻辑（选网卡 / 改 IP / 验证 RTSP） |
| `restore_dhcp.ps1` | 实际的还原逻辑 |

## 用法

### 标准流程

1. 网线一头插录像机，一头插电脑网口（确认网口指示灯亮）；
2. **双击 `configure_directlink.bat`**；
3. 弹出 UAC → 点"是"；
4. 脚本会列出选中的网卡并要求确认，输入 `y` 回车；
5. 看到 `[OK] RTSP 554 可达` 即成功；
6. 打开 LumenArc → 菜单 **文件 → 接入监控直播**，填 `192.168.1.108` / 端口 `554` / 账号 / 通道 1 → 连接。

用完想恢复原来的上网设置，**双击 `restore_dhcp.bat`**。

### 先干跑看看（不改任何配置）

不放心可以先只检查，不会动你的网络：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\configure_directlink.ps1 -DryRun
```

### 高级：指定录像机地址 / 本机地址 / 网卡

```powershell
# 录像机不是 192.168.1.108 时
.\configure_directlink.ps1 -NvrIp 192.168.1.64

# 本机末位改成 101（与别的设备冲突时）
.\configure_directlink.ps1 -HostOctet 101

# 有多张有线网卡、需要指定
.\configure_directlink.ps1 -AdapterName "以太网"

# 组合
.\configure_directlink.ps1 -NvrIp 192.168.1.108 -HostOctet 100 -AdapterName "以太网"
```

## 它做了什么（安全说明）

| 步骤 | 说明 |
|---|---|
| 选网卡 | 只考虑**物理有线**网卡（自动排除 Wi-Fi / 虚拟网卡）；优先选"插了网线且没有默认网关"的那张（直连特征） |
| 存档 | 改动前把原配置写入 `%LOCALAPPDATA%\LumenArc\directlink_state.json` |
| 改动 | 只执行一条 `netsh interface ipv4 set address ... static <ip> 255.255.255.0` |
| 安全闸 | 若该网卡**当前带默认网关**（即正在用来上网），会额外警告并要求二次确认 |
| 验证 | 用 TCP 连 `554` 端口判断（比 ping 更贴近真实需求；部分录像机屏蔽 ICMP） |
| 还原 | `restore_dhcp.ps1` 按存档还原：原来是 DHCP 就还原 DHCP，原来是静态就还原原 IP 和网关，然后删除存档 |

- 需要**管理员权限**（改 IP 的硬性要求），`.bat` 会自动请求提权。
- 除了网卡的 IPv4 地址，**不碰** DNS、防火墙、路由（还原时按存档恢复网关）。
- 不做任何持久化后台驻留。

## 常见提示

| 提示 | 含义 / 处理 |
|---|---|
| `检测到有线网卡，但未插网线` | 网线没插好或没插到这块网口；插好后重跑 |
| `本机没有有线网卡` | 机器没有 RJ45 网口，需 USB 转网口适配器 |
| `该网卡当前有默认网关…` | 这张网卡正在用来上网，改成静态会中断它的上网；确认后再继续 |
| `RTSP 554 暂时不可达` | IP 配好了但录像机没响应：查线、查录像机 IP、查 RTSP 是否开启、查账号权限 |
| `ping 不通（部分录像机屏蔽 ICMP）` | 正常现象，以 `RTSP 554 可达` 为准 |
| Windows 显示"无 Internet 访问" | 直连场景的正常现象，不影响连接录像机 |

## 与 LumenArc 的关系

本目录是**独立脚本**，不参与 LumenArc 的 CMake 构建，不影响程序本体。

> 若希望把"检测到连不上就一键改 IP"做进 LumenArc 界面（识别到 169.254 地址时提示并提供按钮），
> 可以作为后续增强项单独排期。
