# 视频选段变速播放与复合导出（视频+亮度图表+语谱）技术方案

## 1. 背景与需求

调查员复勘时常需要：**反复快放/慢放一个片段**（如火焰突变前后 30 秒），
并把这一段**连同亮度曲线和语谱图一起导出**成视频，用于汇报/庭审演示——
曲线与画面同框，时间点一一对应，比截图拼贴可信得多。

需求（用户口述，2026-08-18）：
1. 选段：在时间轴上标定 A-B 区间（起止点）；
2. 变速播放：该区间按 0.25x~8x 快/慢放（循环复勘）；
3. **一并导出**：选段视频（已变速）+ 亮度曲线（含移动游标）+ 语谱图
   （含移动游标）合成单个 MP4。

## 3. 总体设计（草拟）

### 3.1 选段交互

- 图表 X 轴上 `[` / `]` 键在当前位置打 A/B 标记（复用标签 N 键的交互
  范式）；标记渲染为竖线+区间底纹（ChartPanel 辅助线机制扩类型）；
  拖动标记微调；`Ctrl+[` 清除。
- 选段状态归 ChartPanel 展示、app 层持有（R5：A/B 毫秒唯一 owner 放
  MainWindow→后续归 UiState；随 .vla 保存？——见 Q5）。
- 选段循环预览：position ≥ B 即 seek 回 A（主窗既有 positionChanged
  轮询链路扩展，引擎零改动）；倍速芯片照常生效。

### 3.2 导出管线（离线确定性合成，取证友好）

```
源文件(只读) ──► 进程内逐帧解码（选段 A..B）
                      │ 按倍速做帧映射（§3.4）
                      ▼
              QImage 画布合成（每输出帧）：
              ┌──────────────┬────────────┐
              │              │ 亮度曲线    │  ← 整段光栅化一次 +
              │  视频帧       │ （移动游标） │    每帧只画游标线
              │  （缩放）     ├────────────┤
              │              │ 语谱图      │  ← 同上
              │              │ （移动游标） │
              ├──────────────┴────────────┤
              │ 角标：倍速/区间墙钟/案件号   │
              └───────────────────────────┘
                      │ rawvideo stdin 管道
                      ▼
              ffmpeg 子进程：libx264 CRF18 + 音频(atempo 链) → MP4
```

**为什么是离线合成而不是实时录屏**：实时捕获掉帧/计时不准，产物时间轴
不可信——违反产品第一原则（结果可信）。离线合成每帧时间戳确定性可控。

### 3.3 关键性能决策：图表/语谱只光栅化一次

`renderToImage` 每帧全量重排（resize+polish+scene render）实测十毫秒级，
30s 选段 600 帧 = 分钟级纯绘制，不可接受。改为：

1. 导出开始时对**选段全区间**光栅化一次图表底图（X 轴=A..B）与语谱底图；
2. 每输出帧复制底图 + 画一条游标竖线（x = (t-A)/(B-A)·w）——亚毫秒级；
3. 需要 `ChartPanel::renderToImage` 增加"X 轴定区间"参数（现行为=当前
   视口；加可选参数不改旧调用，行为冻结）。

### 3.4 变速帧映射与音频

- 视频：输出 fps = 源 fps；输出第 k 帧对应源时刻 `A + k·rate·(1000/fps)`。
  快放=跳取（rate≥4 时引擎已有 AVDISCARD_NONREF 先例，导出必须**全参考
  帧解码后按映射取帧**，禁用 skip 保质量）；慢放=重复最近帧。
- 音频：选段 PCM 提取（LibavAnalysisEngine 音频路径模式）→ ffmpeg
  `atempo` 链（0.5-2.0 每级，级联覆盖 0.25-8x）→ 与视频流 mux；
  时长差按短者截齐 + `-shortest`。
- 无音轨/无分析数据（未跑亮度/音频分析）→ 对应面板位显示"无数据"
  占位或隐藏该面板（Q3）。

### 3.5 取证口径（红线）

- 源文件只读，永不改动；
- 产物角标明示**"演示副本 · Nx 变速 · 区间墙钟 A..B"**；
- 命名建议 `LAClip_<原文件名>_<A>-<B>_<N>x.mp4`（沿用 LAMerged 命名
  惯例 §46）；案件模式下登记为案内产物引用（CaseVideoRef outputRefs
  先例）；原始终点：绝对证据以源文件+案内 .vla 为准。

## 4. UI 形态（草拟）

- 选段控件：图表区快捷键 + 图表右键菜单"设为起点/终点"；状态栏显示
  选段时长（fmtSpan 复用）。
- 导出入口：选段存在时主工具栏"导出选段视频..."可用（无选段置灰）；
  对话框：倍速选择（默认当前预览倍速）/ 布局模板 / 输出路径（案件模式
  默认案内 outputs/）。
- 导出中：进度条（帧计数/总帧），可取消（QProcess kill + 临时文件清理，
  P4 登记惯例）。

## 5. 测试策略

- domain：帧映射纯函数（rate/fps/A/B → 源帧序列）单测：0.25/0.5/2/4/8x
  边界、首尾帧归属、非整除舍入。
- app/infra：合成素材（build_tmp/caltest 模式）导出 3s 选段 → ffprobe
  校验产物时长 = 选段时长/rate（±1 帧）、fps、音轨时长；产物帧哈希
  抽样（首/中/尾帧非黑帧）。
- UI 链：ui_chain 扩 A/B 标记 → 循环预览 → 取消导出 无崩溃断言。
- 真机点检：明景 1440p 30s 选段 4x 导出时长/画质/音画同步（±80ms 目检）；
  0.25x 慢放火焰突变段曲线游标与画面对帧一致。

## 7. 风险与应对

- **R-1 大源解码内存**：1440p 逐帧 QImage 全量驻留 = 爆内存 → 管线化
  （解码-合成-写管道流式，背压用管道自然阻塞，C4）。
- **R-2 音画同步**：atempo 后时长与视频帧映射时长舍入差 → 以视频帧
  时间轴为主时钟，音频按 `-shortest` 截齐，允差半帧。
- **R-3 长 GOP 源**：选段起点非关键帧 → 离线解码从 A 前最近关键帧起
  解码丢弃至 A（分析引擎已有同模式，§46 GOP 探测可用作预估）。
- **R-4 语谱缺失**：未跑音频分析时语谱为空 → Q3 占位策略兜住，导出
  不阻断。
