## 1. 现状诊断（为什么难用）

| # | 问题 | 根因 |
|---|---|---|
| D1 | **入口隐形** | 前处理是主窗口视频列表旁的 dock 标签页，不点根本不知道存在 |
| D2 | **流程无导航** | QStackedWidget 静默切页，无步骤指示——用户不知身处哪步、还剩几步 |
| D3 | **信息形态错误** | "能不能拼、顺序对不对"的心智模型是**时间线**；表格 + 64px 小图强迫用户做脑力换算 |
| D4 | **术语技术化** | BLOCK/通道号/转码/OCR 是工程师词汇；火调员的词汇是"缺了哪段、能不能拼、拼完在哪" |
| D5 | **结果无指引** | 执行完输出文件在哪、报告在哪，没有明确出口 |

设计原则：**任务窗口独立、一屏一事、结论先行、术语平实、技术细节可展开但默认折叠**。
取证红线不变：证据截图/OCR 原文/原始观测值全部可见，自动化可人工覆盖（C3/F1-F6）。

## 2. 总体结构

**独立非模态任务窗口**（`PreprocessWindow`，1024×720 起，可最大化），主窗口工具栏显著按钮「素材整理拼接」+ 文件菜单项打开；原 dock 标签页删除（R10）。

顶部**步骤条**（可回退导航，执行中锁定）：

```
● ① 导入素材 ─── ○ ② 校对顺序 ─── ○ ③ 拼接设置 ─── ○ ④ 执行与报告
```

## 3. 四幕布局

### 第①幕 导入素材

```
┌───────────────────────────────────────────────────────────┐
│  ┌─────────────────────────────────────────────────────┐  │
│  │        把监控录像文件拖到这里                            │  │
│  │        或 [点击选择文件…]                              │  │
│  └─────────────────────────────────────────────────────┘  │
│  已导入 10 段（共 96.8 分钟，661 MB）：                     │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ 02-04-52_6m.mp4   10:00  720×480  MP4/H.264   68 MB ✓│  │
│  │ 02-14-52_6m.mp4   10:00  720×480  MP4/H.264   67 MB ✓│  │
│  │ …（探测中显示转圈，完成逐行点亮；失败行红字+原因）        │  │
│  └─────────────────────────────────────────────────────┘  │
│                    [清空重选]        [下一步：自动排序 →]    │
└───────────────────────────────────────────────────────────┘
```

- 拖放接受 .mp4/.avi/.wmv/.flv/.ts/.mts/.dav 等；重复导入自动去重
- probe 后台并发（现有 MediaProbeEngine），完成才放行下一步
- 汇总行给用户"量感"（段数/总时长/总大小）

### 第②幕 校对顺序（核心创新：时间线 + 证据卡片）

```
┌───────────────────────────────────────────────────────────┐
│ ✓ 已按画面时间自动排序：10 段，2 处缺口（共约 4 分 21 秒），无重叠 │
│ ⚠ 03-39-11 段时长仅 75 秒（可能为截断文件），请确认           │
├───────────────────────────────────────────────────────────┤
│ 02:04    02:14    02:24     02:29    02:39 …    03:40      │
│ [█████][█████]░░░░░░░[████][██████████████…████][█]        │
│   ①       ②   缺口4:21  ③      ④ … ⑨           ⑩          │
├───────────────────────────────────────────────────────────┤
│ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐   (横向滚动)│
│ │ [首帧图] │ │ [首帧图] │ │ [首帧图] │ │ [首帧图] │          │
│ │ [尾帧图] │ │ [尾帧图] │ │ [尾帧图] │ │ [尾帧图] │          │
│ │起02:04:53│ │起02:14:52│ │起02:29:11│ │起02:39:10│          │
│ │止02:14:51│ │止02:24:51│ │止02:39:08│ │止02:49:10│          │
│ │ ✓画面时间│ │ ✓画面时间│ │ ✓画面时间│ │ ✓画面时间│          │
│ └─────────┘ └─────────┘ └─────────┘ └─────────┘          │
├───────────────────────────────────────────────────────────┤
│ [←/→ 微调顺序] [手动输入时间…] [重新识别]   [确认顺序，下一步 →]│
└───────────────────────────────────────────────────────────┘
```

**时间线条（ClipTimelineWidget，自绘）**：
- 块位置=墙钟起点、宽∝时长；时间轴刻度自适应（分钟/小时）
- **缺口**=灰色斜纹区 + 「缺口 4:21」标签；**重叠**=红色半透明叠加 + 「重叠 3.2s」
- 点击块 ↔ 选中下方对应卡片并滚动到位（双向联动）
- 无墙钟信息的片段：排末尾等宽排列，块内显示 `?`，卡片红框

**证据卡片**：
- 首帧/尾帧上下排（每张宽约 224px，直接可读 OSD），下挂起/止两行时间
- 尾帧时间为 OCR 实测；无 OCR 时 `~` 前缀灰色推算值；tooltip=**OCR 原文逐字**
- 状态徽标：`✓画面时间`（OCR）/ `✓人工` / `⚠需人工输入` / `⚠时长存疑`
- 双击卡片 → 全尺寸帧预览对话框（人工核读 OSD 后直接点「手动输入时间」）
- 拖动卡片换序（Qt drag 自实现），←/→ 按钮兜底；任何手动操作后时间线/警告即时重算

**结论先行**：顶部一句话总结（顺序依据、段数、缺口/重叠计数与总量、需人工项），替代原"警告汇总"技术腔。

### 第③幕 拼接设置

```
┌───────────────────────────────────────────────────────────┐
│ 拼接方式（已根据片段参数自动选择）：                          │
│  ● 无损拼接（推荐）10 段参数一致，直接拼接不重编码           │
│     画质零损失，预计约 1 分钟                                │
│  ○ 统一格式后拼接                                           │
│     ⓘ 有 3 段参数不同（分辨率 720×480 / 1280×720），必须统一 │
│  ▸ 技术详情（各段参数对比表 / 检测明细）        ← 默认折叠    │
├───────────────────────────────────────────────────────────┤
│ 输出文件夹：[C:\Users\…\前处理输出]              [浏览…]      │
│ 输出文件名：[合并_2026-06-12_02-04-53.mp4]（自动命名，可改）  │
│ ▸ 高级选项（时间戳归一化 / 画质 CRF / 反交错）  ← 默认折叠    │
│                                                           │
│                [← 返回修改顺序]         [开始拼接 ▶]         │
└───────────────────────────────────────────────────────────┘
```

- 单选项由 precheck 驱动：无 BLOCK → 默认无损；有 BLOCK → 默认转码并**平实说明原因**
- 多组输出时逐组一行输出文件名（组概念降级为"输出分组"，不出现在主路径文案）
- 磁盘空间预估在此幕显示（"预计输出约 700 MB，磁盘可用 52 GB ✓"）

## 4. 术语替换表（UI 文案层）

|---|---|

## 5. 实现方案

**不动**：`PreprocessingCoordinator` 全部信号/槽 API、四个引擎、domain、报告格式、单测/集成测试。

**新增**（约 1000 行 UI 代码）：

| 文件 | 内容 | 估算 |
|---|---|---|
| `src/preprocesswindow.h/.cpp` | 窗口框架+步骤条导航+①③④幕+卡片列表 | ~600 行 |
| `src/cliptimelinewidget.h/.cpp` | 时间线条自绘控件（块/缺口/重叠/刻度/点击联动） | ~250 行 |
| mainwindow 接线 | 工具栏按钮+菜单项打开窗口；移除 dock 标签 | ~40 行改动 |

**删除**：`src/preprocesspanel.h/.cpp`（R10 死代码零容忍；其 ↑↓/手输/缩略图缓存逻辑迁入新窗口）。

**i18n**：全部文案走 `lang()`；**手工点检**：发版清单补四幕流程过一遍（规范 7.4，UI 不做自动化）。

**关键交互细节**：
- 窗口非模态：可与主窗口并行（拼接跑着可以继续分析别的视频）
- 执行中关闭窗口 → 确认对话框（取消任务 or 后台继续？v1：取消任务，C2 不留悬空进程）
- 步骤条回退：②③可互退；④执行中锁定；完成后仅可"完成/关闭"
- Enter=下一步主按钮；卡片横向滚动条+鼠标滚轮横向映射
- 时间线数据缺失退化：全部无墙钟 → 等宽序列模式 + "时间未知，请人工确认顺序"横幅

**里程碑**：M1 窗口框架+①幕+步骤条（0.5d）→ M2 ②幕时间线+卡片（1d，核心）→ M3 ③④幕（0.5d）→ M4 接线/删旧面板/手册/点检（0.5d）。合计约 2.5 人日。

> **实施记录（2026-08-02）**：一次批次完成 M1-M4。`src/preprocesswindow.cpp`（~1050 行，四幕+步骤条+卡片拖拽）+ `src/cliptimelinewidget.cpp`（~230 行）新增；`preprocesspanel.*` 已删除（R10）；MainWindow 工具栏右侧金色按钮 + 文件菜单 Ctrl+M 打开独立窗口（WA_DeleteOnClose，每次开启新会话）。卡片拖拽换序经 QDrag + 落点指示条实现，←/→ 按钮兜底；执行中关闭窗口弹确认并取消任务。构建通过，单测 72/72、vla 回归、冒烟启动全部通过。
