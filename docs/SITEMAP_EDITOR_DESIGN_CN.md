# 监控点位图编辑器设计方案（P-74）

> 状态：**已拍板待施工**（2026-08-23 用户三连拍板）
> 归属：P-28 分析报告模块配套子功能（报告「二（三）监控点位图」节的成品图来源）

## 一、需求与定位

报告「二（三）监控点位图」要求：附火灾现场及周边监控点位平面图，标注每个
摄像头位置、编号、拍摄方向和覆盖范围。用户拍板：不做"贴图占位"，做成
**软件内编辑器**——用户导入一张底图，在软件里布点，一键生成**带标准图框**
的成品图，供报告自动取用。

## 二、拍板记录（2026-08-23）

| # | 拍板 | 内容 |
|---|------|------|
| Q1 | 比例尺 | **不画比例尺**——底图多为示意图/截图，无精确比例，图框图名注「示意」 |
| Q2 | 方向表达 | **扇形**（楔形）表达拍摄方向与覆盖范围；**扇面可调**（张角+半径均可调） |
| Q3 | 数量 | **一案一张**点位图（编辑器单实例，反复编辑覆盖） |

## 三、交互设计

**入口**：案件菜单「🗺 编辑监控点位图」（+ 报告向导二（三）节同入口按钮）。

**编辑器布局**（独立对话框，约 1000×700）：

```
┌──────────────────────────────────────────────────┐
│ 工具行：[导入底图] [适应窗口] 缩放[±] [删除选中] [出图保存] │
├────────────┬─────────────────────────────────────┤
│ 机位侧栏    │  画布（底图平移缩放）                  │
│ ┌────────┐ │   · 滚轮缩放、左键空白处拖动平移       │
│ │ D17    │ │   · 侧栏机位拖到画布 → 落点位         │
│ │ 明景   │ │   · 点位拖动改位置；滚轮转朝向         │
│ │ P002   │ │   · 选中点位：属性条调扇面张角/半径     │
│ └────────┘ │                                     │
├────────────┴─────────────────────────────────────┤
│ 属性条（选中点位时）：朝向角 [___]° 张角 [60]° 半径 [__]% │
└──────────────────────────────────────────────────┘
```

**点位视觉**：圆点（机位色）+ 编号标签（白底描边）+ 半透明扇形（同色系
alpha 30%）；选中态加金色描边。机位色与多机时间线 DataPalette 同口径，
图上图下颜色一致可互认。

**撤销**：v1 不做撤销栈（结构简单——拖动/删除即时生效，删除前二次确认）。

## 四、出图（标准图框版成品图）

- **图框**：A4 横向比例外框 + 内框双线，右下角标题栏：
  案件编号 / 图名「监控点位平面示意图」/ 制图（调查员）/ 审核 / 日期 / 图号
  （仿工程制图标题栏样式，黑白线稿风——打印友好）
- **画布区**：底图按"适应内框"等比缩放居中嵌入，点位同比例换算绘制
- **产物**：高分辨率 PNG（2480×1754，150dpi 等效），存案内
  `reports/assets/sitemap.png`；登记案件树（"点位图"节点，点击预览）
- 报告「二（三）」节自动嵌入该图；未绘制时该节显示占位提示

## 五、数据模型（案内持久化）

`<案件>/sitemap.json`（独立文件，不动 case.json 主结构）：

```json
{
  "version": 1,
  "baseImage": "reports/assets/sitemap_base.png",   // 底图复制入案（引用制防丢图）
  "canvasSize": [2480, 1754],
  "points": [
    {"laneRef": "V004", "label": "D17", "x": 0.32, "y": 0.61,
     "headingDeg": 215, "spreadDeg": 60, "radiusPct": 18}
  ]
}
```

- 坐标归一化（相对底图），换图/换分辨率不失位
- laneRef 挂案件机位（V###/P###），机位删了点位标红"孤儿"提示不自动删

## 六、技术方案

- 编辑器：QWidget 自绘画布（同 multicamview/放大镜模式，QTransform 视图变换）
- 出图：QPainter 离屏渲染（与画布共用绘制函数，所见即所得）
- 无第三方依赖；PNG 读写 Qt 原生

## 七、测试

- `sitemap_test`（并入既有 case_test 或独立小套）：JSON 回环、归一化坐标
  边界、孤儿点位标记、出图离屏渲染非空+图框线断言（像素探针）
- 真机验收：导入天河案现场图 → 布 4 点位 → 调扇面 → 出图嵌报告
