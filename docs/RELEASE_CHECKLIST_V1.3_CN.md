# Lumen Arc v1.3.0 发布手工点检清单（案件系统）

> 依据：`docs/DEVELOPMENT_PLAN_V1.3_CN.md` §4.3 手工矩阵 + M3 任务 15 封版要求。
> 自动化测试（case_test 等）覆盖不到的**真实 GUI 场景**逐项过；每项记录
> 通过/失败与备注。测试机需有：真实监控视频若干（含中文路径）、至少两路
> 可校时素材、一块可用磁盘。

## A. 案件生命周期

| # | 步骤 | 预期 | 结果 |
|---|------|------|------|
| A1 | 启动 → 起始页 → 新建案件（必填校验逐项试空） | 编号预览随输入刷新；空必填项不可创建 | |
| A2 | 创建后查看案件根目录 | 目录 `编号-名称`，含 case.json 与 videos/evidence/preprocess/reports/snapshots 子目录 | |
| A3 | 起始页「不再显示」勾选后重启 | 不再弹出；案件菜单可重新打开起始页 | |
| A4 | 最近案件子菜单 | 新→旧最多 10 条，点击直达开案 | |
| A5 | 同一案件双实例打开 | 第二实例锁冲突提示；强制打开可用 | |

## B. 视频入案与数据随案

| # | 步骤 | 预期 | 结果 |
|---|------|------|------|
| B1 | 案件内 Ctrl+O 加 3 路视频（**含中文路径**） | 自动入案登记 V001~V003；徽标 ⏳→✓（指纹后台算完） | |
| B2 | 源视频旁预置旧 `.vla` | 询问导入（默认是），导入后缓存探测直接命中 | |
| B3 | 文件 → 临时打开视频（不入案） | 不入案；`.vla` 读写走源旁老路径（独立模式行为） | |
| B4 | 对一路做校时（三点 OCR） | 徽标出现 ⏰；证据帧在 `<案件>/evidence/calibration/V###/` | |
| B5 | 时间戳框选后关案重开 | 框选记忆随案恢复（不再询问框选） | |
| B6 | 关案重开现场恢复 | 自动打开 lastVideo；ROI/标签/校时/框选全部恢复 | |
| B7 | 前处理窗口案件横幅 | 默认【导入案件】；finalize 后案件面板出现会话与输出登记 | |

## C. 指纹与完整性校验

| # | 步骤 | 预期 | 结果 |
|---|------|------|------|
| C1 | 篡改一路源视频（同尺寸覆写）后开校验 | ⚠ 已变更；「全部重算」必报变更 | |
| C2 | 删除一路源视频后开校验 | ✗ 缺失 | |
| C3 | 4K 播放中触发指纹队列 | 播放不卡顿（单线程低优先级 1MB 分块） | |
| C4 | 移除视频（默认保留案内数据） | 面板消失；案内 .vla/证据帧保留 | |

## D. 重新定位

| # | 步骤 | 预期 | 结果 |
|---|------|------|------|
| D1 | 删源视频重开案件 → 右键单路重定位 | 引用更新、指纹重算、播放正常 | |
| D2 | 单路选大小不一致文件 | 默认拒绝；「仍要采用」后采用且留档（case.json extraFields） | |
| D3 | 批量重新定位：候选目录放改名/移动后的源 | 名+大小匹配 level 2；指纹一致即采用 | |
| D4 | 批量中放同尺寸异内容文件 | 指纹不一致默认拒绝；【仍要采用（留档）】后采用且留档 | |
| D5 | 重定位后继续播放/校时 | 内存状态跟随新路径（图表/ROI 不丢） | |
